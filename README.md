# research-week3-secret-sharing

数据安全与隐私保护课程实验三（任务二）：使用秘密共享实现资产求和

本仓库用 Shamir 与 Brickell 两种秘密共享方案，模拟 m 名资产持有者在不公开
任何个人资产的前提下求出资产总和：

- `code/shamir.py`     Shamir 方案：多项式求值分片 + 拉格朗日插值恢复
- `code/brickell.py`   Brickell 方案：秘密向量内积分片 + 模 p 高斯消元恢复
- `code/asset_sum.py`  主协议：分片 → 节点本地求和 → k 节点恢复总和（含门限验证）
- `code/benchmark.py`  性能对比：分片/求和/恢复耗时、峰值内存、份额存储（5 次平均）
- `result/`            运行结果与性能对比
- `report/`            实验报告（LaTeX, SYSUReport 模板）

## 快速开始

```bash
# 主协议验证（多组输入 + k-1 节点不可恢复测试，两组 (k,n)）
python code/asset_sum.py

# 性能对比（每组重复 5 次）
python code/benchmark.py
```

## 参数

- 有限域：p = 2^31 - 1（梅森素数），总资产公开上界 10^8 << p，避免回绕
- 持有者 m = 4（>=3），门限/份额两组：(k,n) = (3,5) 与 (4,7)
- 纯 Python 标准库实现，无第三方依赖、无向量化

## 协议要点

1. 每名持有者用自己资产独立分片（随机系数各自独立）；
2. 节点 i 把收到的 m 个份额**本地相加**得到总资产份额（秘密共享同态性）；
3. 汇总方收集任意 >=k 个节点总份额恢复总和；不接触个人明文资产，
   不先恢复个人资产再求和。
